    검수자용 리뷰 큐

    사람 검토가 필요한 AI 초안만 모아두는 내부 편집 영역입니다.
    검토가 필요한 분석 결과가 없습니다.
    내부 검수 도구 열기 (관리자 전용)
    이 도구는 내부 운영자용입니다. 검수 큐 등록은 게시가 아니며, 기존 판정 결과(final_decision · policy_confidence · verification_card)를 변경하지 않습니다. 화면에 보이는 것은 인증이 아니라 단순 표시이며, 실제 보호는 서버의 관리자 계정 로그인(세션)으로만 이루어집니다. 여기서 발행되는 결과는 없습니다 (게시가 아님).
    서버 백엔드의 리뷰 API에 연결된 내부 검수 도구입니다. 로그인한 관리자만 사용할 수 있으며, 검증 판정 로직과 공개 화면에는 영향을 주지 않습니다. 사람 검토가 필요한 AI 초안을 모아 검수 큐에 등록하기 위한 내부 작업 영역이며, 이 화면에서 발행되는 결과는 없습니다.
    계정으로 로그인하면 세션 쿠키로 인증됩니다. 검수 도구는 로그인한 관리자만 사용할 수 있습니다.

    분석 결과 → 검수 큐 등록

    현재 화면에 표시 중인 분석 결과를 서버 검수 큐에 사람 검토 필요 상태로 등록합니다. 이 동작은 게시가 아니며, final_decision / policy_confidence / verification_card 값은 변경되지 않습니다. 같은 결과를 다시 등록하면 기존 검수 작업이 그대로 사용됩니다.

    사람 검토됨 승격 (관리자 전용)

    저장된 분석 결과에 human_reviewed_at를 설정/해제합니다. 이는 게시가 아니며 verdict / review_status / 신뢰도 값은 변경되지 않습니다. 비워 두면 현재 화면에 열린 결과의 id를 사용하고, 직접 id를 입력하면 그 결과에 적용됩니다. 승격하면 검증 카드에 "사람 검토됨" 배지가 표시되고, 해제하면 사라집니다.
    토큰을 적용하면 서버 검수 큐를 불러옵니다.

    세부 검증 상태의 의미
    
        
    
          
    
            공식 근거 상태: 공식 후보만 있음
            공식기관 또는 관련 기관 후보는 발견했지만, 기사 핵심 주장과 직접 일치하는 공식 상세문서가 아직 확인되지 않은 상태입니다.
          
    
          
    
            공식 상세문서 상태: 공식기관 후보는 있으나 상세 본문 미확인
            공식기관 후보는 있으나, 상세 페이지 본문이나 원문 문서에서 핵심 주장과 직접 일치하는 문장을 확인하지 못한 상태입니다.
          
    
          
    
            의미 매칭 상태: 의미 매칭 근거 부족
            기사 주장과 수집된 공식·관련 자료 사이의 의미적 연결이 충분하지 않아 자동 확정 판정을 내리기 어려운 상태입니다.
          
    
          
    
            반박/모순 상태: 일부 상충 가능성이 있으나 같은 시점과 대상인지 추가 확인이 필요합니다.
            상충 가능성이 있는 자료 또는 신호가 있지만, 같은 정책, 같은 시점, 같은 대상에 대한 반박인지 사람 검토가 필요한 상태입니다.
          
    
          
    
            사람 검토 필요
            AI가 자동으로 확정하기 어려운 불확실성이 남아 있어 사람이 원문, 공식문서, 시점, 대상, 맥락을 확인해야 하는 상태입니다.

          같은 내용의 주장을 보도한 서로 다른 매체의 수입니다. 얼마나 널리 퍼졌는지를 보여주는 확산 정도이며, 사실 여부 검증이 아닙니다.
          많은 매체가 보도했다는 것이 그 주장이 공식 근거로 뒷받침된다는 뜻은 아닙니다.
        
    
      
    

      
    
        
    검토 상태 배지
    
        
      
          
    • AI 초안: 사람 검토를 거치기 전의 자동 생성 결과입니다.
      • 
          
    • 사람 검토 대기: 사람이 원문·공식문서·맥락을 확인해야 하는 상태입니다.
      • 
          
    • 표현·반박 확인, 사람 검토 대기: 기사의 표현 방식과 반박·모순 신호를 함께 확인해야 해서 사람 확인이 우선적으로 필요한 상태입니다.
      • 
          
    • 사람 검토됨: 사람이 확인을 마친 결과입니다.
      • 
        
    
      
    

      
    
        
    🔥 새로 부상한 이슈 · 공식 확인 진행 중
    
        
    
          최근 새로 퍼지기 시작한 주장에 붙는 표시로, 카드에는 “🔥 새로 부상한 이슈 · 공식 확인 진행 중”으로 나타납니다.
          보도의 최신성·활발함을 나타내며, 주장의 진위와는 무관합니다. 공식 확인이 아직 진행 중이라는 뜻입니다.
        
    
      
    
    
    

    
    
    
      
    
        
    About tickedin
    
        
    tickedin 소개
    
        
    
          정책 뉴스를 정부 공식 1차 출처와 대조해, 무엇이 공식 근거로 확인되는지 투명하게 보여주는
          확산과 공식 근거 유무를 기록하는 독립 인프라입니다. 단정하지 않고, 근거와 출처를 그대로 공개합니다.
        
    
      
    

      
    
        
    
          
    무엇인가요
    
          
    tickedin은 정책·뉴스 속 주장이 어떤 매체로 얼마나 퍼졌는지, 그리고 정부 공식 1차 출처(공식 문서·법령·기관 자료)에 대응 문서가 있는지를 기록하는 독립 인프라입니다.
    
        
    
        
    
          
    왜 만들었나요
    
          
    정책 뉴스는 빠르게 퍼지지만 무엇이 공식 자료로 뒷받침되는지 확인하기 어렵습니다. tickedin은 그 검증 공백을 메우기 위한 도구입니다.
    
        
    
      
    

      
    
        
    어떻게 작동하나요
    
        
        
    AI가 뉴스 속 주장을 공식 자료와 대조해 초안(‘AI 초안’)을 만들고, 사람이 선별적으로 검토합니다(‘사람 검토됨’). 모든 결과는 이 상태로 정직하게 표시됩니다.
    
      
    

      
    
        
    무엇을 약속하나요
    
        
    tickedin은 주장의 진위를 단정하지 않습니다. 검증은 “공식 출처가 그 주장을 뒷받침하는지”를 보여주는 것이지, 절대적 참·거짓 판정이 아닙니다. 근거와 출처를 그대로 공개하고, 새 사실이 확인되면 정정합니다.
